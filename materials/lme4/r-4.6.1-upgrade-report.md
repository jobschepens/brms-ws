## 1. Executive Summary

We conducted a comprehensive cross-platform numerical audit of the Session 29 tutorial (*Model Criticism & Troubleshooting*) across three distinct computational architectures:
- An offline local development baseline.
- Automated GitHub Actions continuous integration runners.
- The high-performance compute cluster **RAMSES** at the University of Cologne.

### Key Audit Findings:
- **Numerical Stability:** Across all 33 computational code cells, **27 cells (81.8%) produced bitwise-identical outputs** between CI and RAMSES HPC. The remaining 6 cells exhibited minor differences confined strictly to floating-point convergence precision ($\Delta < 10^{-5}$) attributable to CPU microarchitecture instruction sets (FMA/AVX) and hardware optimizer timing.
- **Scientific Reproducibility:** 100% of all inferential conclusions, boundary singularity tests, Likelihood Ratio tests, DHARMa residual simulations, and parameter decisions remained **completely invariant** across all three platforms.
- **HPC Performance Scaling:** On RAMSES (allocating 4 physical compute cores), optimization routines demonstrated an additional **~20–23% speedup** over the GitHub Actions CI environment and a **~50–54% cumulative speedup** over the baseline R 4.5.2 release.

## 4. Synthesis & Cross-Platform Integrity

1. **Determinism Across Host Virtualization:** The containerized software stack (`ghcr.io/jobschepens/brms-workshop:working`) behaves consistently across Docker on Linux (Azure), Apptainer on RHEL/Rocky Linux (RAMSES), and local environments.
2. **Microarchitectural Differences:** The tiny discrepancies ($< 10^{-5}$) observed in variance-covariance estimation and CLMM Hessian inversion stem purely from floating-point rounding under different CPU register widths (AVX-512 on RAMSES compute nodes vs. AVX2 on virtualized cloud instances).
3. **Deployment Readiness:** The tutorial and model pipelines are validated and production-ready for both CI/CD automated publication and high-performance computing cluster submission.
