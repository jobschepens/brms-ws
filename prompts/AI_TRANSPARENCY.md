# AI Transparency

This project explores the use of various AI tools for coding, documentation, and debugging. So far, this is a very explorative process and logs do not cover every interaction.

## Models Used

The code and materials in this repository have been developed with the assistance of several AI models, including:

*   **Anthropic Claude Sonnet 4 / 4.5** (Accessed via **GitHub Copilot** education plan)
*   **Google Antigravity / Gemini 3 Pro** (More recent updates)

## Transparency Logs

*   [**Investigating Effect Size Discrepancy**](./Investigating%20Effect%20Size%20Discrepancy.md) — Investigation into a discrepancy between code effect size and hypothesis test estimates.

### Log Format

Logs generally include:
-   **Model**: The AI agent/model used.
-   **Date** & **Objective**: Context of the session.
-   **Verification**: Steps taken to verify the AI's output.
